# Next.js Component Guidelines

- Use function components with React Hooks
- Server Components by default, add 'use client' only when needed
- TypeScript for all components with proper typing
- Tailwind CSS for styling (no custom CSS unless necessary)
- Image components: use `next/image` with proper width/height
- Route structure follows App Router conventions (src/app/)
